# 前后台拆分验收

日期：2026-10-30。范围以 [前后台使用说明](../frontend-areas.md) 和本轮确认计划为准。此次仅重构前端组织与导航，业务 API、数据库、模型协议及持久化任务机制不变。

## 验收矩阵

| 项目 | 验证方式与结果 |
|---|---|
| 双区域、独立首页与导航 | 前台 8 项入口、后台 9 项入口；遍历全部页面、检查单一导航高亮、独立侧栏展开状态。通过。 |
| 真实操作拆分 | 前台资料页不存在维护控件，Skill／图谱维护表单仅后台按需挂载；前台浏览及切换未发送维护请求。通过。 |
| 后台导入、知识编辑 | 浏览器粘贴原创资料，检查解析内容，创建并更新用户知识卡，校验保存版本。通过。 |
| 蒸馏提交与刷新 | 六种方法选择、提示词、章节范围提交契约；提交后进入后台任务，返回前台与刷新仅提交一次。此用例拦截模型任务提交，未产生付费调用。通过。 |
| 真实结果阅读 | 读取此前真实 DeepSeek 生成的仓颉结果、特色成果、状态、引用与导出；浅／深主题。通过。 |
| 前台结果批次隔离 | 默认知识卡严格等于当前结果固定卡片加独立用户补充；阅读其他批次后默认卡和当前指针不变。通过。 |
| 生成入口保留指定结果 | 前台结果进入后台 Agent／Skill 表单，限定卡片来自指定批次，禁用候选不混入；仅打开表单不生成。通过。 |
| Agent 维护与会话 | 前台详情定位同一 Agent，进入后台编辑表单，再返回前台创建真实会话；校验会话固定 Agent 版本，Agent 本身不变。通过。 |
| Skill 维护与多次实践 | 后台创建、编辑并即时查看更新；前台两次独立执行、保存结果与复盘，校验独立记录和固定 Skill 版本。未启用付费 AI 引导。通过。 |
| 图谱与关系 | 前台图／列表及依据阅读，定位同一关系进入后台修改、保存，再回前台核对持久化内容。通过。 |
| 系统页面 | 模型配置、用途分配，系统限制与索引，备份恢复分别显示；模型表单可访问性检查。通过。 |
| 旧链接和上下文 | `/jobs`、`/settings` 重定向保留参数；资料章节、页签、结果、Agent、Skill、关系与实践记录深链接及刷新。通过。 |
| 章节顺序 | 读取书籍快照的 `chapter_ids`，前后台阅读保持声明顺序，避免按记录创建倒序展示。通过。 |
| 原有业务和安全 | 后端全量回归，含版本、结果隔离、来源失效、暂停取消恢复和迁移等既有边界；不可信 Markdown 不执行 HTML、不自动请求远程图片。通过。 |
| 浏览器和可访问性 | Chromium、Firefox、WebKit；双主题、1024／1440／1920 像素宽度、错误页、导航和 WCAG A/AA 自动检查。通过。 |

## 测试证据

- 后端：141 项通过；1 条已有 Starlette/httpx 弃用提示，不影响结果。
- 前端：TypeScript 检查及生产构建通过。
- 三引擎完整浏览器回归：57 项通过，0 失败、0 跳过、0 不稳定；结果见 [汇总](areas-summary.json) 与 [完整报告](areas-browser-results.json)。
- 另以实际按键验证两个首页的跳转主内容及焦点落点，6 项通过，见 [键盘记录](areas-keyboard-results.json)。macOS WebKit 使用 Option（Alt）+Tab 包含链接；其他两引擎使用 Tab。
- 实测浏览器引擎版本见 [版本记录](areas-browser-versions.json)。覆盖浏览器引擎，不代表逐个测试所有品牌浏览器发行版。

## 测试边界

浏览器中的维护与实践使用独立原创验收资料和现有业务 API，校验实际持久化结果；生成提交契约用例明确拦截付费请求。真实蒸馏阅读使用上轮已完成的原创演示资料结果，不以本轮再次调用供应商作为导航重构验收条件。此前真实模型闭环证据仍见 [蒸馏验收](distillation-acceptance.md)。

本轮没有新增付费模型调用，也没有新增账号、权限隔离、数据迁移或部署进程。原有任务的暂停、取消、人工恢复、未知状态不自动重发规则沿用服务端实现。
