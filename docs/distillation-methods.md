# 蒸馏方法与独立结果

每次选择一本已导入书籍、原文章节、一种方法和可选提示词。新界面默认仓颉方法；模型选择独立。所有方法仅使用所选书籍，不执行外部搜索、自动安装、发布或外部脚本。

| 方法 | 运行阶段 | 特色成果 |
|---|---|---|
| 基础 | 片段提炼 → 跨章整合 | 知识卡、摘要、覆盖报告 |
| Book to Skill | 整书结构 → 框架提取 → 方法与反模式 → 术语索引 → 决策表 | 术语、章节参考、决策速查 |
| 仓颉 | 整书理解 → 框架/原则/案例/反例/术语五路提取 → 来源、执行与用途审核 → 能力构造 → 压力测试 → 定点修复 → 跨章整合 | 能力、筛选理由、边界、测试与修复报告 |
| 三生 | 逐章精读 → 知识地图 → 因果链 → 行动与自检 → 整合 | 核心论证、知识地图、自检 |
| 博览 | 中央问题与论证 → 思想框架 → 对话契约 → 文本内证 → 整合 | 价值排序、判断标准、追问与拒答边界 |
| Adler | 书型检视 → 章节分析 → 结构解释 → 批判阅读 → 个人应用 → 整合 | 一页摘要、精读笔记、导图与行动清单 |

各阶段是独立模型请求和持久化步骤，恢复时复用已成功的请求与产物。原版的并行 Agent 提取在本地适配为顺序执行；检视与候选筛选不在中途增加确认阻塞，完整记录供结果页人工核对。外部书评、接收史和事实外查明确标记为未执行，未声称原版完整等价。来源和固定上游提交见 `third-party/distillation-sources.json`。

## 使用

1. 资料详情选择章节，点击“蒸馏所选章节”。选择方法、填写关注问题、选择模型后确认。
2. 任务中心查看方法及当前阶段；暂停在当前模型调用完成后的检查点生效。异常后确认恢复，未知供应商调用不自动重发。
3. 返回“蒸馏结果”查看独立批次，阅读公共内容、特色扩展、原文证据、审核和测试记录。
4. 手动“设为当前结果”。未完成、部分完成、依赖缺失或原文已改变的结果不能启用。
5. 新建 Agent 默认使用当前结果；可为每本书选择另一个完整结果，或明确选择仅原文。也可从结果页生成 Agent、生成实践 Skill 或导出。

切换当前结果不改变既有 Agent 和会话。结果的知识卡版本固定；之后修改卡片不会重写原蒸馏报告。知识卡页可编辑卡片，Agent 按明确版本绑定。

## 结果契约

共同包含：来源与章节版本、方法与版本、提示词、总览、章节摘要、卡片及卡片版本、稳定卡片 ID 关联、适用边界、真实引用、覆盖/失败报告、模型调用与用量。

`extensions` 使用统一的阶段报告结构（章节标题、Markdown 内容、关联卡片、审核结论、测试、修复记录），因此新增方法不需修改通用阅读页面。每种方法通过自己的阶段和提示词决定报告内容，允许不适用字段为空。

引文需与所选片段逐字相同，并保存章节版本、位置及实际文档定位。不能定位的卡保留为停用候选。仓颉/博览还做模型语义审核，仓颉做诱饵情境测试；未通过的能力保持停用。阶段报告是过程记录，最终可用性以知识卡状态为准。引用存在、模型审核、人工核对是三件不同的事，不能据此承诺无幻觉。

原文长段按段落边界拆分，最多约 10,000 字符，重叠 600 字符。整书理解、后续报告与跨章整合通过有界分组覆盖全部输入，超限明确报错，不静默截断。调用量与书长、卡片数和方法阶段有关，仓颉通常最高。

## 扩展和兼容

在 `services/mindchime/distillation/methods/` 增加受信任方法模块，声明 `METHOD`（元信息、版本、来源、阶段）；注册表自动发现。阶段类型为整书理解、片段提取、报告、审核、测试、修复；运行器、模型接口和保存逻辑共同复用。不支持用户上传并运行代码。

所有新任务固定方法清单、模型配置版本和原文版本。恢复时若当前方法模板与固定版本不同，明确阻止，要求原版本代码或新任务。不会拿新提示词覆盖已完成步骤。

旧客户端省略方法继续基础蒸馏；旧 `focus` 映射 `prompt`，两者同时提供必须相同。旧任务仍执行原路径。启动时增量重建可核对的历史基础结果，缺失标记，不补造；原来正在使用的历史结果保留为当前。旧 Agent 不批量重写。

结果、方法元信息与下游依赖进入资产包。包中不包含可执行方法代码；未安装对应方法也可阅读已保存结果。缺依赖与冲突沿用导入预览，不静默覆盖。删除来源及派生知识会清理结果、版本、卡片和任务缓存，并停用关联增强资产；仅删除原文件保留已蒸馏知识。

原文修改、新版本或章节拆合会清除受影响的当前结果选择，历史结果与旧 Agent 绑定保留。特色章节只有关联卡片全部属于已选可用范围时，才进入 Agent/Skill 生成；候选、排除卡及无锚点段落只供阅读，不作为能力上下文。
