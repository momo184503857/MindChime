# 前台与管理后台

MindChime 使用同一个本地应用、业务服务和数据库，按使用流程划分两个区域。首页 `/` 是知识前台，`/admin` 是管理后台；管理员可在侧栏底部切换。两个区域共用主题，分别记住导航展开状态。

本地工作区提供管理员和普通账号。管理员负责后台配置、资产生产、审核与发布；普通账号只能进入前台并使用发布版本。个人会话、成果、实践、记忆和任务按账号隔离。完整规则见 [账号与双蒸馏](dual-distillation-and-access.md)。

## 功能归属

| 前台：日常使用 | 后台：资产与系统维护 |
|---|---|
| 工作台：最近资料、对话、继续实践与个人成果 | 管理概览：资产统计、待处理及失败任务、维护入口 |
| 我的书架：阅读原文、当前结果知识卡、原文证据、总览与历史结果、单项导出 | 资料与蒸馏：导入、批量处理、演示资料、OCR、章节编辑、六种蒸馏方法、卡片审核编辑、结果启用及来源删除 |
| 思想智能体：选择可用 Agent、比较视角、查看知识范围及开始对话 | 智能体管理：生成、手动组合、编辑、复制、归档、删除、知识版本更新及草稿试聊 |
| 对话空间：单聊、群聊、串行讨论、总结及会话版本切换 | 任务中心：全部任务、阶段详情、错误与调用状态、人工确认恢复 |
| 实践 Skills：方法阅读、重复执行、步骤记录、AI 引导、复盘、历史及导出 | Skill 管理：创建、生成、步骤与依赖编辑、关联 Agent、启用及删除 |
| 知识图谱：图／列表浏览、来源筛选、查看候选和已确认关系及依据 | 关系审核：提取候选、手动添加、编辑、确认、停用及修复 |
| 我的成果：生成、编辑、收藏、搜索、行动清单及单项导出 | 模型配置：凭据、协议、能力、连接测试、默认模型及用途分配 |
| 长期记忆：提取、确认、修改、共享、停用及删除 | 系统设置：任务限制、检索索引与明确重建 |
| 业务流程使用管理员指定模型，查看并操作自己的任务 | 数据备份与恢复：完整资产包、原文件携带、恢复预览和冲突处理 |

## 常用流程

1. 管理员登录后台，在“模型配置”检查连接和任务用途分配；普通用户无需配置模型。
2. 在“资料与蒸馏”导入、核对解析内容，选择章节、方法、提示词和模型后明确提交。处理进度可在后台任务中心查看。
3. 查看每次独立结果，核对引用后手动设为当前结果；生成 Agent 或 Skill 时保留指定结果绑定。
4. 在“发布管理”检查并明确发布资产及其依赖，普通用户才能使用。管理员也可在“人物与思想蒸馏”生成、审核并发布独立思想资产。
5. 返回前台阅读、选择 Agent 对话、保存成果，或开始一次独立 Skill 实践。每次实践保留独立输入、Skill 版本、步骤结果与复盘。
6. 管理员需要修改资产时，使用“管理此资料”“维护此智能体”“维护此方法”或“管理此关系”。后台使用“前台查看”返回相应阅读页。

资料切换保留当前章节、页签及打开的蒸馏结果；Agent、Skill、关系保留资产定位，实践记录通过 `run` 参数定位。切换区域不提交任务、不创建实践、不调用生成模型。已有任务由服务端继续执行，具体任务可通过“查看关联内容”回到资料、对话或实践。

前台没有当前结果时仍能阅读原文及独立用户补充，不将同书所有结果混合展示。其他批次在“蒸馏结果”单独阅读，候选与失效状态继续标明。设为当前结果、重跑、卡片修改和版本维护均在后台进行。

## 地址兼容

前台保留 `/library`、`/library/:id`、`/agents`、`/chat/:id`、`/skills`、`/graph`、`/artifacts` 和 `/memories`。

后台新增 `/admin/thoughts`（人物与思想蒸馏）、`/admin/publications`（发布管理）。后台使用 `/admin/library`、`/admin/library/:id`、`/admin/agents`、`/admin/skills`、`/admin/graph`、`/admin/jobs`、`/admin/models`、`/admin/settings` 和 `/admin/data`。

旧 `/jobs` 和 `/settings` 分别重定向到后台任务中心和模型配置，保留查询参数与片段。浏览器历史、刷新和深链接继续有效。

## 实现边界

两个布局共享基础外壳、配色、主题、全局搜索和连接状态；各有独立导航、首页和路由标识。书架展示、Agent 只读资料、结果阅读和证据组件复用。资料管理与阅读分开挂载；Skill、图谱维护组件按需加载，仅后台挂载维护表单。前台保留成果和记忆编辑，因为这些操作属于个人日常使用。

实现与验证记录见 [前后台验收](validation/frontend-areas-acceptance.md)。

页面与表单的常规说明使用问号按需查看，支持悬停、聚焦和点击；约定见 [界面说明规范](ui-help.md)。
